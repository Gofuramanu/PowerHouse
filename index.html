Install Aplikasi PowerHouse IoT

Browser saat ini tidak menampilkan dialog install otomatis. Gunakan salah satu langkah di bawah ini:

Opsi 1: Buka di Google Chrome (Android)

Pindahkan halaman ke Google Chrome lalu ketuk tombol Install:

Opsi 2: Pasang dari Menu Browser
  1. Ketuk ikon menu browser (garis tiga di kanan bawah atau titik tiga di kanan atas).
  2. Pilih Tambahkan ke layar utama (Add to Home screen) atau Instal aplikasi.
  3. Di iPhone (Safari): ketuk tombol Share lalu pilih Add to Home Screen.
