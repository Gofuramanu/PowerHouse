🔒 Mode Read-Only: Akun Anda berstatus Viewer atau belum login sebagai Admin/Operator. Tombol kontrol dikunci demi keamanan.

Mode Operasi Kendali Panel

AUTO: ESP32 mengatur Kipas, AC, dan Buzzer secara otomatis berdasarkan ambang batas suhu dan tetap aman saat internet terputus.
MANUAL: Operator memegang kendali langsung aktuator melalui dashboard (proteksi darurat overheat tetap aktif di ESP32).

🌀 Kipas Pendingin Panel (GPIO 25)

AUTO: ON ≥ 30°C, OFF ≤ 28°C • MANUAL: Kendali via /panel/control/fan

Target Perintah: -- Status Aktual ESP32: --

❄️ AC Split Power House (GPIO 26)

AUTO: ON ≥ 35°C, OFF ≤ 32°C • Proteksi jeda restart kompresor 180 detik

Target Perintah: -- Status Aktual ESP32: --

🔔 Buzzer Alarm Overheat (GPIO 27)

Aktif otomatis (Transistor BC547 Active-HIGH) saat suhu panel ≥ 40°C

Target Perintah: -- Status Aktual ESP32: --

💡 Lampu Indikator Beban (GPIO 14)

Menyala otomatis (Active-HIGH) saat Kipas atau AC sedang beroperasi
